Colombia Travel Planning Document

Site Name

Colombia Travel

I chose this name because it represents the purpose of the website, which is to help people discover tourist destinations in Colombia and learn more about the country.

Site Purpose

The purpose of the Colombia Travel website is to provide information about destinations and cities in Colombia. Visitors will be able to explore different places, learn about their locations, read descriptions, and find useful travel information. The website will have three pages, Home, Places, and Contact.

Scenarios

  • What are some of the best tourist destinations to visit in Colombia?
  • Where are the tourist destinations located?
  • Where can I find more information about traveling in Colombia?

Color Scheme

Color #383557: Will be used for the header, footer, headings, and important elements.

Color #413f5c: Will be used for body text.

Background Color #ececec: will be used for the main background.

Typography

Red Hat Display: Will be used for all the text on the page.
